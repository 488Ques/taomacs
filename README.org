#+TITLE: taomacs — Emacs Configuration
#+AUTHOR: tri.nguyen
#+OPTIONS: toc:2 num:nil

An Emacs configuration built around the built-in =package.el= and
=use-package=. Shared settings, package declarations, bindings, and hooks
live in [[file:init.el][=init.el=]]; commands, helpers, and compatibility code live in
[[file:lisp/][=lisp/=]]. Machine-specific state is kept out of version control.

* Requirements

- *GNU Emacs 31.1+* — uses built-in Eglot with pull diagnostics,
  native terminal child frames, Tree-sitter, and =use-package=.
- *Network access* on first launch, to download packages from GNU ELPA,
  NonGNU ELPA, and MELPA.
- *Git*, for Magit.

GUI and daemon sessions use [[https://github.com/purcell/exec-path-from-shell][exec-path-from-shell]] at startup to import
=PATH= and =MANPATH= from the shell and update =exec-path=. Terminal sessions
keep their inherited environment. After changing shell PATH directories,
restart Emacs; no rebuild is needed. This works independently of Emacs Plus.

[[https://github.com/eki3z/mise.el][mise.el]] enables =global-mise-mode= after initialization, applying mise tool
paths and environment variables per buffer. Install [[https://mise.jdx.dev/][mise]] and ensure the shell
can find it, then run =mise install= in each project. Trust project configs
only when you trust their contents. The current mise.el enables mise's
=experimental= setting when needed.

After editing mise configuration, use =M-x mise-update-dir= to refresh project
buffers (=C-u M-x mise-update-dir= refreshes all managed buffers). Reconnect
existing language servers with =M-x eglot-reconnect= so their processes inherit
the updated environment. Eshell environments update when changing directories.

On macOS, use the stable [[https://github.com/d12frosted/homebrew-emacs-plus][Emacs Plus cask]] (=emacs-plus-app=). It includes
xwidgets, mailutils, tree-sitter, and native compilation. The cask manages its
native-compilation environment and installs =gcc= / =libgccjit= as dependencies;
no custom =LIBRARY_PATH= setup is needed here. It does not capture the user's
PATH, so =exec-path-from-shell= supplies it at startup. No =inject_path= build
configuration is needed.

Recommended external tools (features degrade gracefully without them):

| Tool                   | Used by                     | Notes                          |
|------------------------+-----------------------------+--------------------------------|
| =ripgrep= (=rg=)       | =consult-ripgrep= (=M-s r=) | Fast project search            |
| Symbols Nerd Font Mono | Ghostel prompt glyphs       | Required for Nerd Font icons   |
| Tree-sitter grammars   | =*-ts-mode= major modes     | Install when prompted          |
| =gls= (GNU coreutils)  | Dired listing on macOS      | =brew install coreutils=       |
| =sbcl=                 | SLIME (Common Lisp)         |                                |
| Language servers       | =eglot=                     | Install per language as needed |

Go buffers in =go-ts-mode= use =gopls= through Eglot to organize imports and
format before saving, once the language server is connected. Install =gopls=
and accept the Go grammar installation prompt; =goimports= is not required.
Apheleia still handles formatting for languages configured to use it, but not Go.

For JavaScript and TypeScript, accept the grammar installation prompts for
=javascript=, =typescript=, and =tsx=. TS/TSX buffers start Eglot automatically.
The nearest project-local TypeScript installation selects the server:
TypeScript 7, which has no =tsserver.js=, uses
=node_modules/.bin/tsc --lsp --stdio=. Older versions use
=typescript-language-server --stdio=.
Emacs 31's bundled Eglot supports pull diagnostics; no separately installed
Eglot package is needed.

Eglot connects a buffer to one server, so projects with more tools go through
the =rass= multiplexer ([[https://github.com/joaotavora/rassumfrassum][rassumfrassum]]),
which adds servers by what the project installs:

| Project installs | Added server                                         |
|------------------+------------------------------------------------------|
| =eslint=         | =vscode-eslint-language-server= (diagnostics, fixes) |
| =oxlint=         | the project's =oxlint --lsp=                         |
| =tailwindcss=    | =tailwindcss-language-server= (class completion)     |

=lisp/taomacs-typescript-rass.py= gives the ESLint server the settings VS Code
would. Without =rass= on PATH, Eglot starts the TypeScript server alone.
Install the servers globally through mise:

#+begin_src sh
mise use -g uv npm:typescript-language-server npm:vscode-langservers-extracted \
  npm:@tailwindcss/language-server pipx:rassumfrassum
#+end_src

Flymake shows syntax, type, and lint errors in managed TS/TSX buffers; use
=M-g f= to list diagnostics. Reconnect an already-open buffer with
=M-x eglot-reconnect= after changing TypeScript versions or upgrading Emacs.

Other TypeScript conveniences:
- A header line (=breadcrumb=) shows the file's project path and the enclosing
  class and function.
- Buffers for same-named files carry their directory, such as
  =users/page.tsx=.

Moving or renaming a file does not update its imports: Eglot does not
implement =workspace/willRenameFiles=.

HTML uses =mhtml-ts-mode= for markup and embedded JavaScript and CSS. Type
=div= on its own line and press =TAB= to expand it to =<div></div>= with
point between the tags. Outside an Emmet abbreviation, =TAB= still indents
or completes as usual.

The =css-ts-mode= grammar provides CSS highlighting without an LSP
server. For optional CSS language features, run =M-x eglot= in a CSS buffer;
the built-in Eglot mapping uses =vscode-css-language-server= from
=vscode-langservers-extracted=. Corfu displays completion. See
[[file:docs/web-development-research.md][the web tooling assessment]] for the tradeoffs behind this setup.

Prisma schemas use =prisma-ts-mode=; opening one offers to install its
grammar. Eglot starts the Prisma language server whose major version matches
the project's =prisma= package, through =mise exec=
(=npm:@prisma/language-server@6= for Prisma 6). Format a schema with
=M-x eglot-format-buffer=. =.env= and =.env.*= files use =dotenv-mode=;
Dockerfiles, including =Dockerfile.dev=, use =dockerfile-ts-mode=.

In an Eglot-managed buffer, =M-x eldoc-doc-buffer= shows function
documentation. Use mouse-2 to follow rendered inline Markdown links;
Emacs 31's Eglot preserves the hidden syntax needed to resolve their URLs.

* Installation

On macOS (Apple Silicon, macOS 15+), install the stable prebuilt cask:

#+begin_src sh
brew trust d12frosted/emacs-plus
brew tap d12frosted/emacs-plus
brew install --cask d12frosted/emacs-plus/emacs-plus-app
#+end_src

Launch =/Applications/Emacs.app=. The cask also installs the =emacs= and
=emacsclient= commands. Upgrade without compiling Emacs:

#+begin_src sh
brew upgrade --cask emacs-plus-app
#+end_src

Do not keep an =emacs-plus@N= formula installed alongside the cask: their
command-line links conflict.

On a fresh machine:

#+begin_src sh
git clone <this-repo> ~/.emacs.d
#+end_src

Then launch Emacs. The first start will download and install every
=:ensure t= package automatically — this takes a minute or two. Missing
Tree-sitter grammars are installed on demand, as described below.

Packages come from the official GNU ELPA, NonGNU ELPA, and MELPA servers.
If archive downloads fail with connection resets, check VPN connectivity.
Missing archive indexes are refreshed before package installation, including
when only part of the archive cache exists. To update existing indexes, run
=M-x package-refresh-contents=.

Corfu uses Emacs 31's native terminal child frames; neither =corfu-terminal=
nor its =popon= dependency is needed.

** Tree-sitter grammars

Emacs 31's =treesit-enabled-modes= selects the built-in modes for Bash, CSS,
Dockerfile, HTML, JavaScript, JSON, Python, TypeScript, TSX, YAML, Go, and Go
modules. HTML uses the HTML, JavaScript, and CSS grammars.
=treesit-auto-install-grammar= is set to =ask=: opening a file prompts to
download and compile its missing grammar, then enables the mode without
restarting Emacs. Emacs supplies the grammar repositories and revisions.

Grammar installation requires network access, Git, and a C/C++ compiler.
On macOS, install the Command Line Tools with =xcode-select --install= if
needed. Compiled grammars normally live in =~/.emacs.d/tree-sitter/=.
There is no =yaml-mode= fallback; declining installation or a failed build
leaves YAML without Tree-sitter highlighting and indentation.

For manual installation, load the corresponding mode library first
(for example, =M-x load-library RET yaml-ts-mode RET=), then run
=M-x treesit-install-language-grammar=. Clojure's external mode retains
its own grammar management.

** JSON editing

JSON uses built-in =json-ts-mode=, including =.jsonld=, =.babelrc=,
=.bowerrc=, and =composer.lock=. JSON content detection is retained for
otherwise unrecognized filenames. No =json-mode= or =json-snatcher=
package is needed.

Select JSON text (=C-x h= for the whole buffer), then run
=M-x json-pretty-print= to format it. =M-x json-ts-jq-path-at-point=
displays the path at point and copies it to the kill ring.

** Privileged file editing

Use built-in TRAMP commands; no =sudo-edit= package is needed:

- =M-x tramp-revert-buffer-with-sudo= reopens the current file as root.
- =M-x tramp-dired-find-file-with-sudo= opens the Dired entry as root.

TRAMP handles sudo authentication when needed; these commands do not
grant privileges without authorization.

** Formatting

=apheleia-global-mode= retains Apheleia's default language coverage, so
TypeScript and TSX use Prettier. Projects that install =oxfmt= format
TypeScript and TSX with it instead. Apheleia's bundled resolver prefers
project-local executables and does not download missing tools. Install the
selected formatter separately when needed.

The oxfmt command reads stdin with the real filename, preserving nested
configuration and filename-specific overrides. Go retains its separate
gopls import-organization and formatting hooks.

Built-in =editorconfig-mode= reads project =.editorconfig= files for
indentation, trailing-whitespace trimming, and final-newline settings.
There is no global =whitespace-cleanup= save hook; run
=M-x whitespace-cleanup= for deliberate cleanup. Unspecified properties
retain Emacs or major-mode defaults. Language formatters remain enabled
and need configuration consistent with the project's EditorConfig rules.

** Fonts

GUI frames use =Iosevka= at 15 pt for programming and =Iosevka Etoile= at
15 pt for Org prose, when installed. Org enables variable-pitch text and
visual line wrapping; code, tables, metadata, and hidden indentation stay
monospaced. Restart Emacs after installing the fonts.

** Mode line

=doom-modeline= replaces the built-in mode line while keeping the Modus theme.
It shows the buffer/project path, modified or read-only state, =Lline:Ccolumn=
position (columns start at zero), major mode, Git branch, and Eglot/Flymake
status when active. Encoding, scroll percentage, minor-mode names, and language
runtime versions are hidden.

Icons are enabled in GUI Emacs when =Symbols Nerd Font Mono= is installed;
otherwise the modeline uses text. Restart Emacs to load the configuration.

** Completion and file icons

=nerd-icons-dired= adds file and folder icons in Dired;
=nerd-icons-completion= adds icons to minibuffer candidates alongside Marginalia
annotations. Both require GUI Emacs and =Symbols Nerd Font Mono=.
=kind-icon= restores completion-kind icons in Corfu popups in GUI Emacs.
Restart Emacs to load these integrations.

** Ghostel prompt icons

=Symbols Nerd Font Mono= supplies Doom Modeline icons and the terminal font
fallback for Nerd Font prompt glyphs in Ghostel, including supplementary-plane
glyphs. On macOS, install it:

#+begin_src sh
brew install --cask font-symbols-only-nerd-font
#+end_src

Restart Emacs after installation: font availability is checked at startup.
Missing fonts appear as boxes containing hexadecimal character codes.
Ghostty's bundled fonts are not automatically available to Emacs.


* Portability notes

- *macOS-specific code is guarded.* The =gls= Dired tweak runs only when
  =system-type= is =darwin=. On Linux, use the system's Emacs package;
  the Emacs Plus cask handles macOS native-compilation setup outside this config.
- *Fonts degrade gracefully.* =Iosevka= is applied only if installed;
  otherwise the default face is used.
- *Doom Modeline provides the mode line.* Dired, minibuffer completion, and
  Corfu remain free of package-provided icons. Minor-mode names are hidden;
  the modes remain active. Marginalia annotations and Corfu documentation
  popups remain enabled. The Symbols Nerd Font Mono fallback is retained for
  terminal prompt glyphs in Ghostel; icon-font installation is optional.
- *State is not shared across machines.* Package directories, caches,
  history, tree-sitter grammars, and =custom.el= / =local.el= are
  =.gitignore=d (see below), so each machine builds its own.

* Scrolling

Built-in =pixel-scroll-precision-mode= handles pixel-level trackpad and
mouse-wheel events. There is no Ultra-scroll remapping or custom
momentum/interpolation configuration; scrolling uses Emacs's defaults.

Control+scroll font zoom is disabled, as is touchpad pinch zoom. Keyboard
text scaling (=C-x C-+= / =C-x C--=) remains available.

* Layout

| Path            | Purpose                                             |
|-----------------+-----------------------------------------------------|
| [[file:early-init.el][=early-init.el=]] | Settings that must run before normal initialization |
| [[file:init.el][=init.el=]]       | All shared settings, grouped by topic               |
| =custom.el=     | Emacs =custom-*= output (git-ignored)               |
| [[file:lisp/][=lisp/=]]         | Commands, helpers, and compatibility integrations   |
| =local.el=      | Per-machine overrides, loaded last (git-ignored)    |

Libraries are grouped by responsibility:

- =taomacs-bootstrap.el=: package archive cache checks and refresh.
- =taomacs-files.el=: backup paths and opening the configuration.
- =taomacs-editing.el=: smart line motion, backward deletion, and indentation.
- =taomacs-window.el=: previous-window navigation.
- =taomacs-fonts.el=: font availability checks.
- =taomacs-avy.el=: Avy-to-Embark action.
- =taomacs-ghostel.el=: copy without leaving terminal read-only mode;
  loaded after Ghostel, with =M-w= and =C-w= bound in its read-only keymap.
- =taomacs-go.el=: Go buffer setup, import organization, and formatting.
- =taomacs-html.el=: context-aware Emmet expansion on =TAB= in HTML buffers.
- =taomacs-typescript.el=: Eglot server selection, configuration forwarding,
  TypeScript keys, and formatter selection.
- =taomacs-prisma.el=: Prisma grammar source and version-matched language server.
- =taomacs-session.el= and =taomacs-instance.el=: sessions and separate instances.

** Finding a setting

Open =init.el= with =C-c e=. Use =M-s o= (=consult-outline=) to jump
between topic headings, =M-i= (=consult-imenu=) for package declarations
and variables, or =C-s= to search. Command implementations live in =lisp/=.

|-----------------+-------------------------------------|

New =.el= files open without an automatically inserted template.

** Dired

Use =i= to insert a subdirectory into the same listing, =$= to hide or show
its contents, and =C-M-n= / =C-M-p= to move between subdirectories.
TAB-based inline tree expansion is removed.

** Search & completion

| Key     | Command            |
|---------+--------------------|
| =C-x b= | =consult-buffer=   |
| =C-s=   | =consult-line=     |
| =M-s r= | =consult-ripgrep=  |
| =M-s o= | =consult-outline=  |
| =M-i=   | =consult-imenu=    |
| =M-y=   | =consult-yank-pop= |

Corfu automatically offers completion candidates after two typed characters,
including Eglot suggestions in buffers connected to a language server.
Automatic popups are disabled in Org buffers; =TAB= still completes on demand.
Elsewhere the popup appears after a short pause.

** Buffers

=C-x b= uses =consult-buffer= across all tabs and frames.
=C-x <left>= / =C-x <right>= cycle buffers without tab-local filtering.

| Key       | Command                                              |
|-----------+------------------------------------------------------|
| =C-x x p= | Pin / unpin the buffer (=taomacs-buffer-toggle-pin=) |

After 5 idle minutes, Emacs kills buffers that have not been shown for an
hour; help, Apropos, Info, Man, and Helpful buffers go after 15 minutes. It
never kills pinned buffers (=Pinned= in the mode line; sessions keep the pin),
buffers shown in any window or tab, buffers with a running process, modified file
buffers, =*scratch*=, or =*Messages*=. Each run logs one =Pruned …= line
to =*Messages*=.

=q= in a help or Helpful buffer closes its window and kills the buffer.

** Tools

| Key       | Command          |
|-----------+------------------|
| =C-x g=   | =magit-status=   |
| =C-c t=   | =ghostel=        |
| =C-c o a= | =org-agenda=     |
| =C-c o c= | =org-capture=    |
| =C-c o l= | =org-store-link= |

=C-c t= opens a Ghostel terminal in the current window without creating a
split, reusing the existing =*ghostel*= buffer; =C-u C-c t= creates another
terminal. =C-c T= is unbound. Use =M-x eshell= for Eshell and =C-r= there
for Consult history; =C-c C-r= retains the built-in output navigation.

Eshell is not a terminal emulator. Running =omp= there opens a dedicated
Ghostel buffer in the same working directory, with arguments preserved.
Other Eshell visual commands (such as =top= and =less=) also use Ghostel
instead of =term-mode=. For an unlisted interactive program, use
=ghostel PROGRAM ARGS...= at the Eshell prompt.

Run =omp= directly in a terminal for the full OMP interface. Inside Emacs,
use =C-c t= for Ghostel or =C-x p t= for a terminal in the current project,
then run =omp=. Use =omp --resume= to pick a saved session.

Exit omp with =/exit=. If it was launched directly from Eshell, press =q=
in the exited Ghostel buffer to dismiss it.

** TypeScript

In TypeScript and TSX buffers:

| Key       | Command                            |
|-----------+------------------------------------|
| =C-c l o= | Organize imports                   |
| =C-c l i= | Add missing imports                |
| =C-c l f= | Apply all ESLint (or oxlint) fixes |

Projects that sort imports with an ESLint rule, such as
=simple-import-sort=, should use =C-c l f= instead of =C-c l o=.

** Sessions

| Key       | Command                                                              |
|-----------+----------------------------------------------------------------------|
| =C-c s s= | Save the active session and its checkpoint (=C-u=: under a new name) |
| =C-c s r= | Switch to a saved session                                            |
| =C-c s v= | Revert the active session to its last manual save                    |
| =C-c s c= | Close the active session, leaving =*scratch*=                        |
| =C-c s k= | Delete a saved session                                               |

A session is a named, saved desktop (built-in =desktop.el=): its buffers,
frames, tabs, window layouts, the working directories of its Ghostel and
Eshell buffers, and the repositories of its Magit status buffers (other
Magit buffers are not saved). Emacs starts with no active session. Saving
without an active session asks for a name and makes that session active.

Each Emacs has at most one active session. To work in several sessions at
once, start another Emacs with =C-c n= (macOS otherwise reuses the running
Emacs) and switch it to a session. Opening a session that another Emacs has
open asks for confirmation first. Minibuffer history, saved places, and
bookmarks are single files shared by all instances; the instance that saves
last wins.

While a session is active it is saved automatically when Emacs is idle,
when you switch away, when you close it, and when you quit. Switching or
closing kills every buffer (except =*scratch*=, =*Messages*= and similar),
even when no session is active; switching then restores the chosen session,
while closing leaves a single frame and tab showing =*scratch*=. Emacs still
asks before killing unsaved files or terminals that are running a command.
Terminals come back as fresh shells in their saved directories, without
scrollback; Ghostel skips terminals that were running a program (such as
=omp= launched from Eshell). Deleting the active session keeps its buffers
open but stops saving them. Minibuffer and search history, registers, and
the kill ring are shared by all sessions.

Saving with =C-c s s= also records a checkpoint; auto-saves never change it.
=C-c s v= (after confirmation) kills the session's buffers without saving and
restores the checkpoint, discarding everything since that manual save,
including auto-saves. Like switching, it restarts terminals. Sessions saved
before checkpoints existed need one =C-c s s= before they can be reverted.

Sessions are stored per machine in =sessions/NAME/= (git-ignored).

* Startup and maintenance

Optional tools load on first use: Avy, Embark/Consult integration, Eglot,
SLIME, wgrep, Markdown, and the built-in JSON mode.
Orderless and Cape load through their completion autoloads. Their commands,
bindings, and file associations remain available without loading the
implementations at startup.
Clojure's existing startup setup is retained because loading its tree-sitter
package also registers mode remappings and CIDER integration.

Byte/native compiler warnings are no longer suppressed.
Eglot event logging is disabled with =eglot-events-buffer-config= rather
than replacing JSONRPC internals. To troubleshoot an LSP connection, set it
to =(:size 2000000 :format full)= and run =M-x eglot-reconnect=.

Installed packages are not automatically pruned. An undeclared package can
still be used through =M-x= or be required by another package; review these
uses before deleting it with =M-x package-delete=.

** SQL

Define named connections directly in =local.el=:

#+begin_src emacs-lisp
(setq sql-connection-alist
      '(("local-postgres"
         (sql-product 'postgres)
         (sql-server "localhost")
         (sql-port 5432)
         (sql-user "me")
         (sql-database "app"))))
#+end_src

=C-c d c= runs built-in =sql-connect= to select a connection; =C-c d b=
shows its SQLi buffer. Keep passwords outside this list, in auth-source.
The =sql-indent= extension is removed; built-in SQL indentation remains.

SQL has no custom word or schema completion. Cape supplies filename
completion only; Eglot supplies completion in managed language buffers.

* Per-machine customization

Create =local.el= in this directory for overrides that should not be
shared (it is loaded last and is git-ignored). For example:

#+begin_src emacs-lisp
;; local.el
(setq magit-repository-directories '(("~/proj/" . 1)))
#+end_src
