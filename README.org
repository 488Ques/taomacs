#+TITLE: taomacs — Emacs Configuration
#+AUTHOR: tri.nguyen
#+OPTIONS: toc:2 num:nil

A single-file Emacs configuration built around the built-in =package.el=
and =use-package=. Shared settings are grouped by topic in
[[file:init.el][=init.el=]]; machine-specific state is kept out of version control.

* Requirements

- *GNU Emacs 30.1+* — the config uses =setopt=, the built-in =which-key=,
  =project-mode-line=, tree-sitter, and =modus-operandi-tinted=. Developed
  against Emacs 30.2.
- *Network access* on first launch, to download packages from GNU ELPA,
  NonGNU ELPA, and MELPA.
- *Git*, for Magit.

Recommended external tools (features degrade gracefully without them):

| Tool                 | Used by                   | Notes                          |
|----------------------+---------------------------+--------------------------------|
| =ripgrep= (=rg=)         | =consult-ripgrep= (=M-s r=)   | Fast project search            |
| A Nerd Font          | doom-modeline, nerd-icons | Install via command below      |
| Tree-sitter grammars | =*-ts-mode= major modes     | Install via command below      |
| =gls= (GNU coreutils)  | Dired listing on macOS    | =brew install coreutils=         |
| =sbcl=                 | SLIME (Common Lisp)       |                                |
| =mise=                 | =global-mise-mode=          | Per-project tool versions      |
| Language servers     | =eglot=                     | Install per language as needed |

Go buffers in =go-ts-mode= use =gopls= through Eglot to organize imports and
format before saving, once the language server is connected. Install =gopls=
and the Go tree-sitter grammar; =goimports= is not required. Apheleia still
handles formatting for languages configured to use it, but not Go.

For JavaScript and TypeScript, install the =javascript=, =typescript=, and
=tsx= tree-sitter grammars. TS/TSX buffers start Eglot automatically: when
the nearest project-local TypeScript installation has no =tsserver.js=,
Eglot uses its =node_modules/.bin/tsc --lsp --stdio= (TypeScript 7).
Otherwise it uses =typescript-language-server --stdio= for older
TypeScript installations; install that server separately for TS 6
projects. This config installs GNU ELPA Eglot 1.20 or newer when needed:
the Emacs 30 bundled version cannot display TypeScript 7's pull diagnostics.
Flymake shows syntax and type errors in managed TS/TSX buffers; use
=M-g f= to list diagnostics. Reconnect an already-open buffer with
=M-x eglot-reconnect= after changing TypeScript versions or upgrading Eglot.

The =css-ts-mode= grammar provides CSS highlighting without an LSP
server. For optional CSS language features, install
=vscode-langservers-extracted= (provides =vscode-css-language-server=)
and run =M-x eglot= in a CSS buffer; the built-in Eglot mapping already
knows that server. Corfu displays completion, and Apheleia uses
project-local =oxfmt= for TS/TSX formatting when installed. See
[[file:docs/web-development-research.md][the web tooling assessment]] for the tradeoffs behind this setup.

In an Eglot-managed buffer, =M-x eldoc-doc-buffer= shows function
documentation. Rendered inline Markdown links in that buffer are buttons:
use =RET= or mouse-2 to open their URLs.

* Installation

On a fresh machine:

#+begin_src sh
git clone <this-repo> ~/.emacs.d
#+end_src

Then launch Emacs. The first start will download and install every
=:ensure t= package automatically — this takes a minute or two. Once it
settles, run the two one-time setup commands below.

** One-time setup

1. *Install icon fonts* (otherwise the modeline and Dired show □ boxes):

   #+begin_src
   M-x nerd-icons-install-fonts
   #+end_src

2. *Install tree-sitter grammars* for the languages you edit. The
   =major-mode-remap-alist= routes Python, JS, TS, YAML, JSON, CSS, and
   Bash to their =-ts-mode= variants, which need grammars present:

   #+begin_src
   M-x treesit-install-language-grammar
   #+end_src

   Sources for the configured languages are listed in
   =treesit-language-source-alist=. Restart Emacs after installing a grammar
   so the startup-only mode remapping picks it up.

* Portability notes

- *macOS-specific code is guarded.* Native-compilation library-path setup
  (Homebrew =gcc=/=libgccjit=) and the =gls= Dired tweak only run when
  =system-type= is =darwin=, so the config also runs on Linux — you simply
  lose those Mac-only niceties.
- *Fonts degrade gracefully.* =IBM Plex Mono= is applied only if installed;
  otherwise the default face is used.
- *State is not shared across machines.* Package directories, caches,
  history, tree-sitter grammars, and =custom.el= / =local.el= are
  =.gitignore=d (see below), so each machine builds its own.

* Scrolling

=ultra-scroll= is enabled for pixel-precise trackpad and mouse scrolling; it
enables the built-in =pixel-scroll-precision-mode= itself. If scrolling is not
smooth on your device, use =M-x ultra-scroll-check= to inspect its pixel
events. To compare with Emacs's built-in scrolling in the same session, run
=M-x ultra-scroll-mode= to disable ultra-scroll, then enable
=M-x pixel-scroll-precision-mode=.

** Finding a setting

Open =init.el= with =C-c e=. Use =M-s o= (=consult-outline=) to jump
between topic headings, =M-i= (=consult-imenu=) for function and variable
definitions, or =C-s= to search within the file.

** Sessions

| Key     | Command                                       |
|---------+-----------------------------------------------|
| =C-c s s= | Save the session (buffers, windows, frames)   |
| =C-c s r= | Restore the saved session                     |

Sessions are entirely manual: =desktop-save-mode= is never enabled, so Emacs
neither asks to save on exit nor restores anything at startup.  =C-c s s=
overwrites =desktop/.emacs.desktop= (git-ignored) without asking, =C-c s r=
reads it back into the running Emacs.  The desktop lock file is released
right away, so a session never gets tied to one Emacs process.

Exiting Emacs asks for confirmation even when all buffers are saved. This is
separate from the optional session save above.

* Startup and maintenance

Optional tools load on first use: Avy, Embark/Consult integration, Eglot,
SLIME, wgrep, sudo-edit, Markdown, and the JSON/YAML fallback modes.
Orderless and Cape load through their completion autoloads; desktop loads
when a session command is invoked. Their commands, bindings, and file
associations remain available without loading the implementations at startup.
Clojure's existing startup setup is retained because loading its tree-sitter
package also registers mode remappings and CIDER integration.

Dired subtree insertion refreshes icon overlays without reverting the
directory buffer. Byte/native compiler warnings are no longer suppressed.
Eglot event logging is disabled with =eglot-events-buffer-config= rather
than replacing JSONRPC internals. To troubleshoot an LSP connection, set it
to =(:size 2000000 :format full)= and run =M-x eglot-reconnect=.

Installed packages are not automatically pruned. An undeclared package can
still be used through =M-x= or be required by another package; review these
uses before deleting it with =M-x package-delete=.

** SQL completion

The SQL setup uses built-in =sql.el=, =sql-indent=, and SQL-scoped Cape
dabbrev completion. After connecting, =M-x sql-list-table= (columns) or
=M-x sql-list-all= (tables) makes those names available to completion in
SQL buffers. Repeat after schema changes. Schema-aware LSP completion would
be a separate workflow change, not a prerequisite for this setup.

* Per-machine customization

Create =local.el= in this directory for overrides that should not be
shared (it is loaded last and is git-ignored). For example:

#+begin_src emacs-lisp
;; local.el
(setq magit-repository-directories '(("~/proj/" . 1)))
#+end_src
