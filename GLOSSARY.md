# taomacs

A personal Emacs configuration; these terms describe how work in it is organised.

## Language

**Session**:
A named, saved workspace of buffers, tabs, and window layouts for one area of work, such as AIC, Team Management, or Personal.
_Avoid_: Desktop, activity, workspace, project

**Active session**:
The one session the current Emacs is working in and saves to; there may be none.
_Avoid_: Current desktop, loaded session
